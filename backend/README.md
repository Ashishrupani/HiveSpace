# Welcome to the Hive Space backend 👋

This is developed using Node.js, Express.js, Websocket.io.
Database - MongoDB
Authentication - Clerk
AI - Gemini


## Get Started

1. Install Dependencies

   ```bash
   npm install
   ```

2. Setup .env file

   ```bash
   PORT=port_number
   CLIENT_URL=your_frontend_url
   CLIENT_URL_OTHER=your_other_frontend_url
   CLERK_PUBLISHABLE_KEY=your_clerk_key
   CLERK_SECRET_KEY=your_clerk_secret_key
   MONGO_DB_URI=your_mongodb_url
   GEMINI_API_KEY=your_gemini_api_key
   ```

3. Start the app

   ```bash
   npm start or npm run start
   ```
